# ICOR for Life - Quick Notes Menu 0.1.0

The first release: a global hotkey you record yourself, a menu bar icon,
a capture box that appends to today's daily note, and an `obsidian://`
door for Raycast, Alfred and Shortcuts. Desktop only.

## What it does

- **Record your own hotkey.** Settings, Record hotkey, press the chord.
  Nothing is registered until you do (Tom's decision, 2026-09-09). The
  chord is shown and editable as an Electron accelerator string; a chord
  another app already holds is refused with a notice.
- **Press it anywhere.** Obsidian comes to the front with the capture
  box. Enter saves, Shift-Enter breaks the line, Escape cancels.
- **The line lands in today's daily note**, `- HH:mm text` by default,
  created when missing, appended atomically.
- **The menu bar icon** carries Quick note (with your chord as its
  label), Open daily note and Settings. Exactly one vault owns the icon
  and the hotkey ("This vault owns the menu bar and the hotkey"); "Show
  menu bar icon" hides the icon while keeping the hotkey.
- **`obsidian://icor-quick-note?vault=<name>&text=<text>`** appends the
  text as plain text; without text it opens the box.

## Not in this release

A rich popover under the icon, and a status text beside the icon (the
`setStatus` hook exists and is wired to nothing).

## Reviewed against

Flint's 2026-09-09 read of the 1.13.7 bundle and the Electron and
Chromium sources: `@electron/remote` is enabled on every vault window by
Obsidian itself; a second `globalShortcut.register` of a held chord
returns false and keeps the old callback; `obsidian://` does not raise
an open vault's window. Every rule from that read is in this version
(unregister before register, the boolean checked, no `unregisterAll`,
release on unload and on `beforeunload`, the window brought forward by
the plugin). Flint's review of this build is the release gate.

## Beta round 1

Tom's first live test (2026-09-09) showed the icon as a fixed black
bitmap, invisible on the dark menu bar: `@electron/remote` serializes a
`NativeImage` by value on its way to the main process, so the template
flag set in the renderer never arrived. Fixed by writing the embedded
PNGs into the plugin folder as `menubar-iconTemplate.png` and `@2x` and
giving the Tray that path, so the main process builds the image itself
and the `Template` suffix marks it.

## Not verified outside the test suite

This version was built and gated without a running Obsidian. The parts
only a live vault can settle are the first beta round's check:

- The tray icon appears once, survives a plugin reload and a Cmd-R
  reload without a duplicate, and disappears on disable.
- The recorded chord fires from another application and the vault window
  comes forward (`show()` + `app.focus({ steal: true })`).
- The "taken chord" notice when another application holds the chord,
  and a second vault with ownership off registering nothing.
- The capture box focuses its textarea on open and Enter saves while
  Shift-Enter breaks the line under the modal scope.
- The `obsidian://` door from Raycast and from Apple Shortcuts, including
  the URL-encoded `text`.
- The "Settings" menu item opening this plugin's tab (`app.setting` is
  private and read through a guard).
- The folder picker control on the settings page and the declarative
  `validate` messages.
- The template image tinting in the dark and light menu bar, and how
  Iris's icon reads at 16 px next to the system's own.

## Requires Obsidian 1.13.0

The settings page uses the 1.13 declarative API (`getSettingDefinitions`)
and carries no `display()` fallback. `@electron/remote` has been enabled
on vault windows for far longer; the floor is the settings API.

## Install

Copy `main.js`, `manifest.json` and `styles.css` from this release into
`.obsidian/plugins/icor-for-life-quick-notes-menu/` and enable the plugin
under Settings, Community plugins. Then record a hotkey and set the daily
note folder and date format to match your Daily notes plugin.
