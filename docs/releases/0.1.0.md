# ICOR for Life - Scratchpad 0.1.0

The first release: a floating note window you reach from any application
with a hotkey you pick yourself, a menu bar icon, and an `obsidian://`
door for Raycast, Alfred and Shortcuts. Desktop only.

This is a clone of Raycast Notes built on a real Obsidian popout window.
It was first built as "Quick Notes Menu", a capture box that appended a
line to the daily note; Tom realigned it to this shape on 2026-09-09,
before anything shipped, so the capture box and the daily-note append are
gone and there is nothing to migrate.

## What it does

- **Press your hotkey anywhere.** The window comes forward with your last
  note in it. Press it again and it goes away; so does Escape. Nothing is
  registered until you record a chord.
- **It is a real Obsidian editor.** Your other plugins work in it. The
  tab strip and the view header are hidden inside that window only.
  Readable line width is your own setting: a narrow window fills its
  width, a fullscreen one centres the column the way the main window
  does. The inline title stays: it is where a note is renamed.
- **A new note is filed by date and named from the clock,**
  `00 Daily Scratchpad/2026/09/202609091812` with the defaults, which is
  what the core Unique note creator would call it. Both formats are
  settings. You rename by typing in the title, which is Obsidian's own
  rename.
- **A toolbar at the top right:** always on top, the actions palette,
  browse notes, new note. The drag handle is the whole top band behind
  it: under the default hidden frame style Obsidian puts the window's
  drag region on the title bar and the tab strip, both of which this
  window hides.
- **Fullscreen and maximise work.** Always on top switches off while the
  window is expanded, because macOS does not allow both, and comes back
  when it is not.
- **A character count at the bottom centre.**
- **Ten actions, each with a real command behind it,** and, for eight of
  them, a chord that is live only inside the window and that collides with
  no Obsidian default.
- **Browse notes** across the whole scratchpad folder, subfolders
  included: pinned first, then newest change first, each row showing the
  note's first line, when it was last opened and how long it is, with pin
  and delete on the row. Delete goes to your configured trash with an Undo
  in the notice.
- **`obsidian://icor-scratchpad?vault=<name>&text=<text>`** creates a note
  with that text and shows the window; without text it just shows it.

## Not in this release

The bottom-right round button from the Raycast reference is deliberately
not here: in Raycast it is Raycast AI's text tools, and this window is a
real Obsidian editor where every text action already has three homes.
Iris ruled it out and reserved no space for it. Copy Deeplink and Create
Quicklink are Raycast concepts with no Obsidian equivalent and are not in
the palette; the palette has no placeholder rows.

A status text beside the menu bar icon (the `setStatus` hook exists and
is wired to nothing).

## Beta round 1, fixed

Tom's first live test on 2026-09-09 found seven defects. All seven are
fixed in the same round, and each fix carries a test that was watched
fail on the exact defect it names before it was believed.

1. **The find bar opened under the traffic lights** with its close button
   unreachable. The reserved top band never existed: the rule was written
   as `body.icor-scr-window .view-content`, which is (0,2,1), against
   Obsidian's own `.workspace-leaf-content[data-type='markdown']
   .view-content { padding: 0 }` at (0,3,0). The band selector now carries
   the leaf class and wins, and the test computes both numbers rather than
   trusting the reading.
2. **None of the chords did anything.** Obsidian's `Scope` matches a key
   by `event.key`, and macOS rewrites `event.key` under Option: Option-N
   arrives as "Dead". The Scope is gone. One keydown listener on the
   popout's document, capture phase, matches `event.code` against the same
   table the chips are drawn from, and touches nothing else.
3. **"Open in main window" only focused Obsidian.** `getLeaf('tab')`
   is `createLeafInTabGroup()`, which calls `getMostRecentLeaf()` with no
   root and therefore searches the root split and the popouts together, so
   the scratchpad's own leaf won and the note opened inside the popout.
   The tab now goes into the main window's own tab group, a note already
   open there is revealed instead of opened twice, and the scratchpad
   hides itself unless it is pinned above everything. See round 2 below
   for the second half of this one.
4. **The find bar could not be closed.** Besides defect 1, Escape was
   taken by the plugin. Escape now closes an open find bar first, yields
   to a palette or a menu second, and hides the window only when nothing
   else is listening. The order lives in one pure function and the test
   pins it.
5. **The find bar could not be navigated:** Enter and the arrows did
   nothing. Same root as defect 2, second half: `pushScope` replaces the
   window's single scope pointer and `Scope.handleKey` falls through to
   its parent, not down the stack, so a scope pushed on top of the
   search's own swallowed every key the search needed. Nothing is pushed
   any more, and the new listener ignores every key that is not in the
   table and every key pressed inside the find bar.
6. **New notes landed in the folder root as "Untitled".** They are filed
   into a dated subfolder and named from the clock now, and the inline
   title is shown so a note can be renamed by typing in it.
7. **The window could not be dragged, and the green button was dead.**
   The drag region was the pill alone, a small target in the corner with
   nothing to say so; it is the whole top band now. Fullscreen and
   maximise were disabled to protect always on top; they are allowed
   again and the flag is restored from the setting when the window comes
   back, with the saved rectangle never taken from an expanded window.

## Beta round 2, fixed

Tom's second live test passed defects 1 and 3 to 7 and found two more.

8. **In fullscreen the note hugged the left edge of the screen** while the
   main window centres the same note. The plugin forced readable line
   width off inside the window, which is right at 480 pixels and wrong at
   2000. The override is deleted rather than replaced by a width class the
   plugin toggles: Obsidian's whole readable-line-width behaviour is a
   `max-width` on the editor's sizer, and a max-width larger than the
   space available never binds, so a narrow window fills its width and a
   wide one centres, inline title included, with nothing written by this
   plugin at all. A member who turned readable line width off keeps a
   full-width window at every size.
9. **"Open in main window" made a split column,** with no tab header and
   no close button, because `createLeafInParent(rootSplit, -1)` inserts
   into the split itself rather than into a tab group. The route that
   works is `getMostRecentLeaf(rootSplit)` with the root named, then
   `setActiveLeaf` on that leaf, then `getLeaf('tab')`, which now finds
   the main window's tab group instead of the popout's.

## Not verified outside the test suite

This version is built and gated without a running Obsidian. The parts
only a live vault can settle:

- The window opens at the intended size with no 600 by 600 flash, and
  comes back where it was left.
- The hotkey shows and hides it from another application.
- The top band drags the window, and the traffic lights do not collide
  with the pill or with the find bar.
- Fullscreen: the chrome still reads with the notch and the menu bar out
  of the way, and always on top comes back on the way out.
- The chords fire inside the window and nowhere else. Press Cmd-P in
  Obsidian's main window while the scratchpad is hidden: the command
  palette must open.
- Cmd-F opens the find bar, Enter and the arrows walk the matches, and
  Escape closes the bar without hiding the window; a second Escape hides
  the window.
- The two modals open in the popout rather than in the main window, and
  the group labels, the row actions and the accent dot render as Iris
  drew them.
- A new note lands in today's subfolder with the caret in the body, and
  typing in the title renames the file.
- Fullscreen centres the column and the inline title with it, and a 480
  pixel window still fills its width.
- "Open in main window" lands as a real tab in the main window's tab
  group, with a tab header and a close button.
- Cmd-W closes for real and the next hotkey opens a fresh window.
- After a relaunch the popout is recognised and hidden.
- The Outliner and the hover preview work inside the window.
- The ownership handover between two open vaults, and the losing vault
  releasing the chord and the tray within a moment.
- The tray icon appears once, survives a Cmd-R reload without a
  duplicate, and disappears on disable.
- `setVisibleOnAllWorkspaces` was NOT used, so a `show()` from a
  fullscreen Space may switch Spaces. Flint flagged it; it is left out
  until Vera has tested the behaviour without it.

## Requires Obsidian 1.13.0

The settings page uses the 1.13 declarative API
(`getSettingDefinitions`) and carries no `display()` fallback. The popout
APIs are 0.15.3 and 0.15.4; `@electron/remote` has been enabled on vault
windows for far longer. The floor is the settings API.

## Install

Copy `main.js`, `manifest.json` and `styles.css` from this release into
`.obsidian/plugins/icor-for-life-scratchpad/` and enable the plugin under
Settings, Community plugins. Then record a hotkey and set the scratchpad
folder.
